# RU

Мы снова собрались в комнате отправки билдов, чтобы нажать на те самые кнопки, которые превращают рабочую сборку в снапшот. И сегодня у нас первый такой шаг для ветки **0.3.0**.

В этом снапшоте мы занялись вещами, которые не кричат о себе в списке фич, но очень сильно меняют ощущения от игры. Теперь в CubeOS появилась **видимая рука от первого лица**, **рендер блоков и инструментов в руке**, а ещё **звуки ломания и постановки почти для всех блоков**.

Что это значит на практике? Мир стал заметно живее. Добыча ощущается как добыча, строительство — как строительство, а действия игрока больше не происходят “в пустоте”.

Что, и это всё? Пока да — но именно с таких шагов и начинается настоящий survival. Этот снапшот открывает цикл **0.3.0**, а значит впереди ещё больше изменений, которые будут постепенно собирать CubeOS в полноценную игру.

Вместе с этим pre-release мы также впервые прикладываем **CubeOS Launcher** для macOS. Пока это ранний отдельный лаунчер, который умеет видеть GitHub Releases, скачивать совместимые macOS-сборки CubeOS и запускать установленные версии из одного окна.

Приятной добычи!

## Launcher

Вместе со снапшотом мы впервые прикладываем **CubeOS Launcher** для macOS.

Это отдельное приложение, которое показывает релизы CubeOS, скачивает поддерживаемые macOS-сборки и запускает уже установленные версии. Пока лаунчер находится на ранней стадии и доступен только на macOS, но именно с него начинается более удобный способ управлять снапшотами и будущими релизами CubeOS.

# EN

We gathered in the build release room once again to press the buttons that turn a working build into a snapshot. Today marks the very first public step for the **0.3.0** branch.

This snapshot focuses on features that may not look massive on a checklist, but change how the game feels in a very noticeable way. CubeOS now has a **visible first-person hand**, **held block and tool rendering**, and **breaking/placing sounds for almost every block family**.

What does that mean in practice? The world feels much more alive. Mining feels like mining, building feels like building, and player actions no longer happen in a visual vacuum.

Is that all? For now, yes — but this is exactly how a real survival update begins. This snapshot opens the **0.3.0** cycle, and more changes will keep building CubeOS toward a fuller survival game.

With this pre-release we are also shipping **CubeOS Launcher** for macOS for the first time. It is still an early standalone launcher, but it can already browse GitHub Releases, download compatible macOS builds, and launch installed CubeOS versions from one place.

Happy mining!

---

## Changes

* Added a visible first-person hand
* Added held block rendering
* Added held tool rendering
* Added breaking sounds for almost all block families
* Added placing sounds for almost all block families
* Added the first public **CubeOS Launcher** macOS asset to the pre-release

---

## Launcher

This snapshot also introduces **CubeOS Launcher** for macOS.

It is a separate app that lists CubeOS releases, downloads supported macOS builds, and launches installed versions. The launcher is still early and macOS-only for now, but it begins a much smoother path for browsing and installing future snapshots and releases.

---

## Technical Changes

* Added a baseline first-person hand render path
* Implemented held block presentation
* Implemented held tool presentation
* Added sound events for block breaking
* Added sound events for block placing
* Expanded sound coverage to almost all current block types
* CubeOS Launcher now correctly distinguishes the game macOS asset from its own launcher asset in GitHub Releases
